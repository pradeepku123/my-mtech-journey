# 🧩 Advanced Reasoning and Planning

> **Course Code**: Elective 6 (NLP / Reasoning Pool) | **Semester**: 3  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

Covers LLM Reasoning, Large Reasoning Models (LRMs like OpenAI o1/o3, DeepSeek R1), reasoning-oriented prompting, inference-time scaling (search, MCTS, PRMs), verification, RL for reasoning (STaR, PPO for chain-of-thought), knowledge representation, and multi-LLM collaboration.

---

## 📋 Syllabus & Topic Checklist

- [ ] **Reasoning Foundations**: Logical reasoning vs Statistical pattern matching, Chain-of-Thought mechanisms
- [ ] **Large Reasoning Models (LRMs)**: Architecture and training techniques of reasoning models (DeepSeek-R1, o1)
- [ ] **Inference-Time Scaling**: Tree Search (MCTS), Process Reward Models (PRMs), Self-Consistency, Majority Voting
- [ ] **Verification & Correctness**: Formal verification, Theorem proving (Lean/Coq with LLMs), Executable code verification
- [ ] **RL for Reasoning**: STaR (Self-Taught Reasoner), Rule-based rewards, GRPO (Group Relative Policy Optimization)
- [ ] **LLM-Based Planning**: Hierarchical Task Networks (HTN), PDDL planning integration, Replanning strategies
