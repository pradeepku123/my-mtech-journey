# 🏗️ Architecting AI Systems

> **Course Code**: Elective 4 (Systems Pool) | **Semester**: 3  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

End-to-end AI system design and architectural patterns, AI system components, agentic AI architecture, Agent Development Lifecycle (ADLC), MCP/A2A gateways and agent protocols, scalability, performance optimization, resiliency, cloud integration, and governance.

---

## 📋 Syllabus & Topic Checklist

- [ ] **AI Architectural Patterns**: Monolithic vs Microservices AI, Event-driven AI architectures, Lambda/Kappa for ML
- [ ] **Agentic System Architecture**: Agent Development Lifecycle (ADLC), MCP (Model Context Protocol), A2A (Agent-to-Agent) gateways
- [ ] **Scalability & Latency Patterns**: Model serving topologies, Caching (Semantic cache), Batching, Distributed inference
- [ ] **Resiliency & Fault Tolerance**: Fallbacks, Circuit breakers for API LLMs, Graceful degradation, Rate-limiting
- [ ] **Cloud-Native Integration**: Cloud-native AI blueprints, Serverless ML (AWS Lambda, Bedrock Studio), Gateway routers

---

## 🔗 Key Resources

- **Book**: *Designing Machine Learning Systems* by Chip Huyen
- **Protocol**: Anthropic Model Context Protocol (MCP) Specification
