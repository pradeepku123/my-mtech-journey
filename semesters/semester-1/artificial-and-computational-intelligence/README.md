# 🧠 Artificial and Computational Intelligence

> **Course Code**: Core 3 | **Semester**: 1  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

This course explores fundamental AI principles, classical search algorithms, knowledge representation, automated reasoning, constraint satisfaction, fuzzy logic, genetic algorithms, and computational intelligence paradigms.

---

## 📋 Syllabus & Topic Checklist

- [ ] **AI Foundations & Problem Formulations**: Intelligent Agents, state-space representations, goal formulations
- [ ] **Uninformed Search Strategies**: BFS, DFS, Depth-Limited, Iterative Deepening, Uniform Cost Search
- [ ] **Informed (Heuristic) Search**: A* Search, Greedy Best-First Search, Heuristic Admissibility & Consistency, AO*
- [ ] **Adversarial Search & Games**: Minimax, Alpha-Beta Pruning, Monte Carlo Tree Search (MCTS)
- [ ] **Constraint Satisfaction Problems (CSP)**: Backtracking, Arc Consistency (AC-3), Constraint Propagation
- [ ] **Knowledge Representation & Logic**: Propositional Logic, First-Order Logic, Inference, Knowledge Graphs
- [ ] **Computational Intelligence**: Fuzzy Logic systems, Evolutionary Computation (Genetic Algorithms), Swarm Intelligence
