# 🤖 Agentic AI Systems

> **Course Code**: Elective 3 (Specialization / General Pool) | **Semester**: 3  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

Foundations of Agentic AI, LLMs as Autonomous Agents, Prompt engineering for agents, agent design patterns (ReAct, Plan-and-Execute, Reflexion), memory and context management, multi-agent collaboration, tool calling, safety, governance, and MLOps deployment of agentic pipelines.

---

## 📋 Syllabus & Topic Checklist

- [ ] **Agentic Foundations**: LLMs as Reasoning Engines, Perception-Action Loops, Tool Execution
- [ ] **Agent Architectural Patterns**: ReAct (Reasoning + Acting), Plan-and-Execute, Reflexion, Self-Correction loops
- [ ] **Memory Management**: Short-term, Long-term, Episodic memory, Vector DB integration, Conversation buffer
- [ ] **Tool Calling & Function Calling**: Tool definitions, JSON schema generation, API execution, Error handling
- [ ] **Multi-Agent Collaboration**: Hierarchical agents, Peer-to-peer agent networks, LangGraph, AutoGen, CrewAI frameworks
- [ ] **Safety, Governance & Evaluation**: Goal drift prevention, Human-in-the-loop (HITL), Guardrails, Agentic benchmarks

---

## 🔗 Key Resources

- **Frameworks**: LangGraph, AutoGen, CrewAI, Llama-Agents
- **Papers**: *ReAct: Synergizing Reasoning and Acting in Language Models* (Yao et al.)
