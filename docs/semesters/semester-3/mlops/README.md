# 🚀 MLOps (Machine Learning Operations)

> **Course Code**: Elective 5 (Systems & MLOps Pool) | **Semester**: 3  
> **Institution**: BITS Pilani WILP (M.Tech AIML)  
> 🌟 **SDET → MLOps Career Bridge Core**

---

## 📖 Course Overview

Covers production-grade MLOps, CI/CD pipelines for ML, experiment tracking, model registries, automated testing & model validation, data & concept drift monitoring, feature stores, containerization (Docker, Kubernetes), model serving (FastAPI, Triton), and cloud deployments (AWS SageMaker / Bedrock).

---

## 📋 Syllabus & Topic Checklist

- [ ] **ML Pipeline Automation**: Airflow, Prefect, Kubeflow Pipelines, DVC (Data Version Control)
- [ ] **Experiment Tracking & Registry**: MLflow, Weights & Biases, Model registry lifecycle states
- [ ] **Model Testing & QA**: Behavioral testing for ML (Deepchecks, Evidenty AI), PyTest for ML pipelines
- [ ] **Model Serving & API Design**: FastAPI, gRPC, Triton Inference Server, TorchServe, vLLM
- [ ] **Containerization & Orchestration**: Docker, Kubernetes, Helm charts for ML deployments
- [ ] **Monitoring & Observability**: Data drift (KS-test, PSI), Concept drift, Prometheus, Grafana alerts
- [ ] **AWS Cloud Deployments**: SageMaker endpoints, AWS Lambda ML inference, Bedrock integration
