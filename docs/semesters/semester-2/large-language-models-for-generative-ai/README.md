# 🤖 Large Language Models for Generative AI

> **Course Code**: Elective 2 (NLP / GenAI Pool) | **Semester**: 2  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

Foundations of Large Language Models (LLMs), pre-training, inference acceleration, fine-tuning techniques (LoRA, QLoRA), preference alignment (RLHF, DPO), prompt engineering, scaling laws, RAG architectures, LLMs as agents, evaluation, and security/privacy.

---

## 📋 Syllabus & Topic Checklist

- [ ] **LLM Architecture & Pre-training**: Decoder-only transformers (Llama, Mistral, GPT), FlashAttention, Rotary Position Embeddings (RoPE)
- [ ] **Inference Optimization**: KV Cache, Quantization (AWQ, GPTQ, GGUF), Speculative Decoding, vLLM, Ollama
- [ ] **Efficient Fine-Tuning**: PEFT, Parameter-Efficient Fine-Tuning, LoRA, QLoRA, Prefix Tuning
- [ ] **Preference Alignment**: Alignment problem, RLHF (Reward Modeling + PPO), Direct Preference Optimization (DPO), KTO
- [ ] **Prompt Engineering & Reasoning**: Chain-of-Thought (CoT), Tree of Thoughts (ToT), In-Context Learning, Few-shot prompting
- [ ] **Retrieval-Augmented Generation (RAG)**: Chunking strategies, Embeddings, Vector DBs (FAISS, Chroma, Pinecone), Hybrid Search, Reranking
- [ ] **LLM Evaluation & Safety**: Ragas, DeepEval, Red teaming, Jailbreak prevention, Hallucination detection
