# 💬 Natural Language Processing

> **Course Code**: Elective 1 (NLP Pool `#`) | **Semester**: 2  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

Covers text preprocessing, tokenization, word embeddings (Word2Vec, GloVe), sequence modeling, language models, Machine Translation, Sentiment Analysis, Information Extraction, Knowledge Graphs, and state-of-the-art NLP applications.

---

## 📋 Syllabus & Topic Checklist

- [ ] **Text Preprocessing & Tokenization**: Stemming, Lemmatization, BPE, WordPiece, SentencePiece
- [ ] **Vector Space Models & Embeddings**: TF-IDF, Word2Vec (CBOW, Skip-gram), GloVe, FastText
- [ ] **Language Modeling & Recurrent Models**: N-gram LMs, RNN/LSTM Language Models, Perplexity
- [ ] **Contextual Embeddings**: ELMo, BERT (Masked LM, Next Sentence Prediction), RoBERTa
- [ ] **Sequence Tagging & Parsing**: POS tagging, Named Entity Recognition (NER), Dependency Parsing
- [ ] **Applications**: Sentiment Analysis, Text Classification, Question Answering, Summarization
- [ ] **Indic NLP**: Processing Indic languages, Multilingual models (mBERT, XLM-R)
