# 🧠 Deep Neural Networks

> **Course Code**: Core 5 | **Semester**: 2  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

Covers neural network fundamentals, linear networks for regression/classification, deep feedforward networks, backpropagation, network training/regularization/optimization, transfer learning and fine-tuning, Convolutional Neural Networks (CNNs), Recurrent Neural Networks (RNNs/LSTMs), Attention mechanisms, Transformers, and Vision Transformers (ViTs).

---

## 📋 Syllabus & Topic Checklist

- [ ] **Feedforward Neural Networks**: Perceptrons, Multi-Layer Perceptrons (MLPs), Activation Functions (ReLU, GELU, Swish)
- [ ] **Training & Optimization**: Backpropagation, Autograd, Loss functions, SGD, AdamW, Learning Rate Schedulers
- [ ] **Regularization**: Dropout, Weight Decay (L2), Batch Normalization, Layer Normalization, Early Stopping
- [ ] **Convolutional Neural Networks (CNNs)**: Convolutions, Pooling, ResNet, EfficientNet architectures
- [ ] **Recurrent Neural Networks**: RNNs, LSTMs, GRUs, Sequence-to-Sequence models, Vanishing Gradients
- [ ] **Attention & Transformers**: Self-Attention, Scaled Dot-Product, Multi-Head Attention, Transformer Encoder-Decoder
- [ ] **Vision Transformers**: ViT architecture, Patch embeddings, Self-attention for vision tasks
- [ ] **Transfer Learning & Fine-Tuning**: Pre-trained backbones, Feature extraction vs fine-tuning
