# 🎮 Deep Reinforcement Learning

> **Course Code**: Core 6 | **Semester**: 2  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

Explores Markov Decision Processes (MDPs), Dynamic Programming, Model-Free Control, Value-Based methods (Q-Learning, DQN), Policy-Based methods (REINFORCE, Actor-Critic, PPO, SAC), Model-Based RL, Reward Modeling, and RL applications in autonomous systems and LLM alignment.

---

## 📋 Syllabus & Topic Checklist

- [ ] **MDP Foundations**: States, Actions, Rewards, Transition Probability, Discount Factor, Bellman Equations
- [ ] **Dynamic Programming**: Policy Evaluation, Policy Iteration, Value Iteration
- [ ] **Model-Free Learning**: Monte Carlo methods, Temporal Difference (TD) learning, Q-Learning, SARSA
- [ ] **Value-Function Approximation**: Deep Q-Networks (DQN), Experience Replay, Target Networks, Double DQN
- [ ] **Policy Gradient Methods**: REINFORCE algorithm, Policy Gradient Theorem, Variance Reduction (Baselines)
- [ ] **Actor-Critic Methods**: A2C/A3C, Proximal Policy Optimization (PPO), Soft Actor-Critic (SAC)
- [ ] **Advanced RL & Alignment**: Model-based RL, Inverse RL, RLHF (Reinforcement Learning from Human Feedback)
