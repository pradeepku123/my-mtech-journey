# 🎓 Semester 4: Capstone Dissertation & Industry Project

> **Course Code**: Core Dissertation | **Semester**: 4  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

The 4th semester is dedicated to an end-to-end Capstone Dissertation or Workplace Industry Project under faculty & industry mentorship. Learners formulate an original research/engineering problem, conduct experiments, develop production-grade AI models, and write a thesis defense report.

---

## 📋 Dissertation Phases & Milestones

- [ ] **Phase 1 — Problem Formulation & Literature Review**: Topic selection, research question, literature survey
- [ ] **Phase 2 — System Architecture & Methodology**: Proposed model design, dataset preparation, baselines
- [ ] **Phase 3 — Experimentation & Evaluation**: Implementation, hyperparameter tuning, metrics, error analysis
- [ ] **Phase 4 — Thesis Draft & Defense**: Dissertation writing, peer review, final presentation & defense

---

## 💡 Industry & Workplace Project Ideas (SDET → AI Bridge)

1. **Autonomous Test Generation Agent**: Agentic LLM pipeline for auto-generating Playwright/Cypress end-to-end tests from natural language specs.
2. **AI-Driven Automated Flaky Test Diagnosis**: GNN & Multi-modal model to analyze test logs, video recordings, and DOM trees to identify flaky test root causes.
3. **Enterprise RAG & Code Security Auditor**: Fine-tuned LLM with static code graph analysis to audit CI/CD security vulnerabilities.
