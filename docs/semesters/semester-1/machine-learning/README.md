# 🤖 Machine Learning

> **Course Code**: Core 4 | **Semester**: 1  
> **Institution**: BITS Pilani WILP (M.Tech AIML)

---

## 📖 Course Overview

Introduction to Machine Learning principles, supervised and unsupervised paradigms, Bayesian learning (MAP, Bayes Optimal, Naive Bayes), linear regression/classification models, non-linear models, decision trees, MDL principle, instance-based learning, SVMs, ensemble learning, and model evaluation/comparison.

---

## 📋 Syllabus & Topic Checklist

- [ ] **ML Foundations & Workflow**: Supervised, Unsupervised, Semi-supervised learning, ML lifecycle
- [ ] **Bayesian Learning**: MAP Hypothesis, Bayes Optimal Classifier, Naive Bayes Classifier
- [ ] **Linear Models**: Linear Regression (Gradient Descent & Normal Eq), Logistic Regression, Softmax
- [ ] **Non-Linear Models & Trees**: Decision Trees, Information Gain, Gini Impurity, MDL Principle, Pruning
- [ ] **Instance-Based Learning**: k-Nearest Neighbors (k-NN), Distance Metrics, Lazy Learning
- [ ] **Support Vector Machines (SVM)**: Hard & Soft margin, Dual formulation, Kernel trick (RBF, Polynomial)
- [ ] **Ensemble Learning**: Bagging, Random Forests, Boosting (AdaBoost, XGBoost, LightGBM), Stacking
- [ ] **Clustering & Unsupervised**: k-Means, Expectation-Maximization (EM), Gaussian Mixture Models (GMM)
- [ ] **Model Evaluation & Comparison**: Cross-Validation, ROC-AUC, Precision-Recall, SHAP, Bias-Variance Tradeoff
